# MiniAgent 项目文件架构

## 1. 当前项目结构

src/mini_agent/
├── __init__.py
├── agent.py              # Agent Loop 核心
├── chat.py               # 交互入口（组装根）
├── llm/
│   ├── base.py           # BaseLLM 抽象接口
│   └── client.py         # DeepSeekLLM
└── tools/
    ├── __init__.py       # 统一导出
    ├── base.py           # Tool 基类（校验 + to_schema）
    ├── calculator.py     # CalculatorTool
    ├── current_time.py   # CurrentTimeTool
    ├── read_file.py      # ReadFileTool（分页）
    ├── list_files.py     # ListFilesTool
    ├── write_file.py     # WriteFileTool（写入确认）
    └── registry.py       # 工具注册表
├── context.py            # token 估算 / 视图构建 / 摘要压缩（无状态函数层）
├── memory.py             # MemoryManager（有状态记忆管家）
